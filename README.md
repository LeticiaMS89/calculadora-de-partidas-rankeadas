# 🎮 Calculadora de Partidas Rankeadas

Uma calculadora interativa para determinar o nível de um jogador baseado em vitórias e derrotas.

---

## 📋 O que faz

- Calcula o saldo de vitórias (vitórias - derrotas)
- Determina o nível do jogador
- Exibe resultado com badge colorido

---

## 📊 Níveis

| Vitórias | Nível |
|----------|-------|
| < 10 | Ferro |
| 11-20 | Bronze |
| 21-50 | Prata |
| 51-80 | Ouro |
| 81-90 | Diamante |
| 91-100 | Lendário |
| ≥ 101 | Imortal |

---

## 🚀 Como usar

1. Abra `index.html` no navegador
2. Digite vitórias e derrotas
3. Clique em "Calcular Nível"
4. Veja seu resultado!
